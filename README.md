# Artificial Intelligence in Cybersecurity

Casdoor is an AI-First Identity and Access Management (IAM) / AI MCP Gateway. OpenSSF Scorecard - Security health metrics for Open Source. Cybersecurity AI (CAI) is a lightweight, open-source framework that empowers security professionals to build and deploy AI-powered offensive and defensive automation. Gapps is an security compliance platform. Apache HertzBeat is an AI-powered next-generation real-time observability system. Wazuh is an open source platform used for threat prevention, detection, and response. Langfuse is an open source LLM engineering platform. Trivy is a comprehensive and versatile security scanner. ModelScan is an open source project from Protect AI that scans models to determine if they contain unsafe code. Cortex is a powerful observable analysis and active response engine. LangKit is a toolkit for monitoring LLMs. Zeek is a powerful network analysis framework. garak is a computer security tool that provides information about LLM security vulnerabilities. OpenRMF OSS is an open source application for managing, viewing, and reporting of your DoD STIG checklists, SCAP Scans and Nessus Patch Scans. NIST AI Risk Management Framework. OpenAM is an access management solution that includes Authentication, SSO, Authorization, Federation, Entitlements, and Web Services Security. OACC (Object ACcess Control) is an advanced Java Application Security Framework. Apache Shiro is a powerful and easy-to-use Java security framework that performs authentication, authorization, cryptography, and session management. Dependency-Check is a Software Composition Analysis (SCA) tool that attempts to detect publicly disclosed vulnerabilities. NVIDIA Morpheus is an open AI application framework that provides cybersecurity. Snort 3 is the next generation Snort IPS (Intrusion Prevention System). OSSEC is an Open Source Host-based Intrusion Detection System. LunaTrace is a supply chain security and auditing tool

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
