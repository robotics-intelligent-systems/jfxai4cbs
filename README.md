# Artificial Intelligence in Cybersecurity

Chocotea is a library that generates postman collection, environment and integration tests. Bucket4j is a java rate limiting library. Harvester is a modern, open, interoperable, hyperconverged infrastructure (HCI) solution built on Kubernetes. Langfuse is an open source LLM engineering platform. Testcontainers is a Java library that supports JUnit tests. ModelScan is an open source project from Protect AI that scans models to determine if they contain unsafe code. Cortex is a powerful observable analysis and active response engine. LangKit is a toolkit for monitoring LLMs. Zeek is a powerful network analysis framework. garak is a computer security tool that provides information about  LLM security vulnerabilities. NIST AI Risk Management Framework. pac4j security engine for Java. OpenAM is an access management solution that includes Authentication, SSO, Authorization, Federation, Entitlements, and Web Services Security. OACC (Object ACcess Control) is an advanced Java Application Security Framework. The Alloy SDK brings together a set of tools that you can use for your different Application Layer Encryption needs. CMAK is a tool for managing Apache Kafka clusters. Apache Shiro is a powerful and easy-to-use Java security framework that performs authentication, authorization, cryptography, and session management. Dependency-Check is a Software Composition Analysis (SCA) tool that attempts to detect publicly disclosed vulnerabilities. NVIDIA Morpheus is an open AI application framework that provides cybersecurity developers with a highly optimized AI framework and pre-trained AI capabilities that allow them to instantaneously inspect all IP traffic across their data center fabric. Snort 3 is the next generation Snort IPS (Intrusion Prevention System). OSSEC is an Open Source Host-based Intrusion Detection System. The multi-agent ranking framework (MARK) aims to provide all the building blocks that are required to build large scale detection and ranking systems.
